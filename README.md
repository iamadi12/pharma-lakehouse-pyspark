# Pharma Commercial Lakehouse (PySpark + Delta Lake)

A compact medallion pipeline that turns raw pharma commercial feeds — weekly prescriptions (TRx/NRx),
rep calls and an HCP master — into model-ready KPIs, with SCD Type 2 history, config-driven KPIs
and control-total audits.

```
 data/raw (CSV)          BRONZE                  SILVER                          GOLD
 ─────────────      ──────────────────     ─────────────────────────      ───────────────────────
 rx_weekly.csv  ──► raw + ingest meta  ──► typed, deduped, validated, ──► trx_by_zip3_month
 rep_calls.csv  ──► raw + ingest meta  ──► ZIP3 + month grain        ──► nrx_by_specialty_month
 hcp_master_*   ─────────────────────────► dim_hcp (SCD Type 2)      ──► calls_by_zip3_month
                                                                            ▲
                                                          kpi_config.json ──┘   (+ control-total audit)
```

## What it demonstrates
- **Medallion architecture** – bronze keeps raw data with `_ingested_at` / `_source_file`;
  silver casts types, removes duplicates and invalid values, and standardises to ZIP3 and month
- **SCD Type 2** – two HCP master snapshots; changed specialties close the old row
  (`valid_to`, `is_current = false`) and open a new version, new HCPs are inserted
- **Metadata-driven KPIs** – each gold table is defined in `kpi_config.json`
  (source, measure, aggregation, grain, optional HCP attributes); a new KPI needs no code
- **Audit** – TRx control totals compared between silver and gold; rows dropped
  from bronze to silver are reported
- **Delta Lake or Parquet** – uses Delta when `delta-spark` is installed, otherwise Parquet

## Run it
Locally (Java 11/17 required):
```bash
pip install -r requirements.txt
python generate_data.py     # synthetic data -> data/raw/
python pipeline.py          # writes data/lake/{bronze,silver,gold}
```
On **Databricks Free Edition**: upload the repo, run `generate_data.py`, then `pipeline.py`
(or paste the functions into a notebook). Delta is built in.

## Add a KPI
```json
{
  "name": "nrx_by_specialty_month",
  "source": "rx",
  "measure": "nrx",
  "agg": "sum",
  "grain": ["brand", "specialty", "month"],
  "hcp_columns": ["specialty"]
}
```

## Ideas for extension
- Incremental loads with `DeltaTable.merge` instead of full overwrites
- Orchestrate the layers as Databricks Lakeflow Jobs or an Airflow DAG
- Deploy with Databricks Asset Bundles and run data-quality gates before each gold write

*All data is synthetic and generated by `generate_data.py`; brand names are made up.*
